# STUDIQ — Your Personal Learning System

เว็บไซต์ต้นแบบสำหรับวางแผนการเรียนและติดตามงาน สร้างด้วย HTML, CSS และ JavaScript โดยไม่ต้องติดตั้ง framework

## ไฟล์ในโปรเจกต์
- `index.html` — โครงสร้างทุกหน้า
- `styles.css` — ดีไซน์ Responsive และ 6 ธีม
- `app.js` — ฟังก์ชันและการบันทึกข้อมูล

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิด `index.html` ใน Chrome, Edge หรือ Firefox
3. หากแก้โค้ด แนะนำให้เปิดโฟลเดอร์ด้วย VS Code

## ฟีเจอร์
- Dashboard
- Smart Planner: เพิ่ม แก้ไข ลบ และทำเครื่องหมายงานเสร็จ
- Smart Schedule: สร้างตารางจากงานและช่วงเวลาว่าง, ส่งออก PNG, พิมพ์ A4/บันทึก PDF
- Focus Room: Pomodoro timer และบันทึกเวลาโฟกัสเมื่อจบรอบ
- My Notes: เพิ่ม แก้ไข ค้นหา และลบโน้ต
- Progress Analytics: กราฟสถิติจากข้อมูลที่บันทึก
- Habit Tracker: เพิ่มนิสัยและเช็กอินรายวัน
- Theme Studio: ขาว-ดำ, ดำ-ขาว, ฟ้าพาสเทล, ชมพูพาสเทล, เขียวพาสเทล, แดง
- Settings: เป้าหมาย/เวลาส่วนตัว, สำรองและนำเข้าข้อมูล JSON

## หมายเหตุ
- ข้อมูลบันทึกไว้ใน LocalStorage ของเบราว์เซอร์นั้น ๆ ไม่มีบัญชีผู้ใช้หรือการซิงก์ข้ามอุปกรณ์
- Smart Schedule ใช้การจัดลำดับตามความสำคัญ/กำหนดส่งและช่วงเวลาว่าง เป็นระบบ rule-based ไม่ใช่ AI
- ปุ่มพิมพ์ใช้หน้าต่างพิมพ์ของเบราว์เซอร์ ผู้ใช้สามารถเลือก “Save as PDF”
- Google Fonts ใช้เมื่อมีอินเทอร์เน็ต แต่เว็บยังใช้ฟอนต์สำรองได้เมื่อออฟไลน์
- หากเผยแพร่ด้วย GitHub Pages ให้เก็บทั้ง 3 ไฟล์ไว้ในโฟลเดอร์เดียวกันและอัปโหลดทั้งหมด
